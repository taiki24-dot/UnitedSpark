# United Spark 練習日程ボード

メンバーの練習できる日と時間を集めて、決定事項・出欠・チャットまでできるチーム用ページです。
保存先は **Firebase Firestore**（無料枠で6人なら十分）、公開は **Vercel** を想定しています。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面とデザイン |
| `app.js` | アプリ本体（入力・結果・チャット・管理者など） |
| `firebase.js` | 保存先（Firestore）への接続 |
| `config.js` | **ここにFirebaseの設定値を貼る** |
| `firestore.rules` | Firestoreのルール（Firebaseに貼る） |

## セットアップ手順

### 1. Firebaseプロジェクトを作る
1. https://console.firebase.google.com を開いて「プロジェクトを追加」
2. 名前を入れる（例：united-spark）。Googleアナリティクスはオフでよい

### 2. Firestoreを作る
1. 左メニュー「構築」→「Firestore Database」→「データベースを作成」
2. ロケーションは `asia-northeast1`（東京）
3. 「本番環境モード」で開始

### 3. ルールを貼る
1. Firestoreの「ルール」タブを開く
2. `firestore.rules` の中身を全部コピーして貼り付け
3. 「公開」を押す

### 4. ウェブアプリを登録して設定値を貼る
1. 左上の歯車 →「プロジェクトの設定」→「マイアプリ」→ `</>`（ウェブ）
2. ニックネームを入れて登録（Firebase Hostingはチェック不要）
3. 表示される `firebaseConfig` の値を、`config.js` の同じ項目に貼り付ける
   （この値は公開されても問題ありません）

### 5. GitHubに上げる
1. GitHubで新しいリポジトリを作る
2. このフォルダの中身（`index.html` など全部）をアップロードする

### 6. Vercelで公開する
1. https://vercel.com で「Add New → Project」→ さっきのリポジトリを選ぶ
2. Framework Preset は **Other**、Build Command と Output Directory は **空のまま**
3. 「Deploy」

### 7. 初回の設定
公開URLを開くと「初期設定」画面が出ます。
メンバーの名前（1行に1人）と、管理者になる人を決めて「この内容ではじめる」を押してください。
そのあと管理者で入り、「管理者」タブの「メンバー管理」から全員の合言葉を設定します。

## パソコンで動作確認したい時
`file://` で直接開くと動きません。このフォルダで次のどちらかを実行して、表示されたURLを開いてください。

```
python3 -m http.server 8000
npx serve
```

## 保存の仕組み
- 予定・決定事項・出欠・チャット・メンバー・管理者・合言葉は **Firestore** に保存され、全員に即反映されます
- 保存に失敗した時は自動で再送します。電波が悪い時の書き込みは端末にも残り、つながったら送られます
- 選んだ名前・テーマ・既読位置はそのスマホの中だけに保存されます

## 注意
- **公開URLを知っている人は、誰でもデータを読み書きできます。** URLは身内だけに共有してください
- 合言葉は「うっかり他人の名前で入る」を防ぐためのものです。本気の不正は防げません
- ルールで文字数や項目の形は制限していますが、アクセス制限はありません。心配になったら Firebase の App Check や Authentication の追加を検討してください
- Claudeの画面で作っていた時のデータ（メンバー・予定など）は引き継がれません。初期設定からやり直しです
